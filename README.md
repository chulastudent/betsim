## ทำไมต้อง betsim
คนกล้าคิดนอกกรอบ(อย่างผม) ไม่มีวันไปใช้ชีวิตต่อไปอีก 30-40 ปี กับ `"การลงทุนระยะยาวแบบกระจายความเสี่ยง"` 
ซึ่งก็คือของคนที่ยอมรับความธรรมดาไปทั้งชีวิต (เป็นหมาเป็นแกะต่อไปครับ)
ผมไม่ได้มาสอนให้ใครรวยเร็ว ผมมาสร้างเครื่องมือให้คนที่ `"รู้อยู่แล้วว่าตัวเองต้องทำอะไร"` แค่ยังไม่มีระบบซิ่งเท่านั้นเอง

## Dizzkramer
โปรแกรมนี้เป็นเพียง simulation เพื่อการศึกษาสำหรับคุณ (และการลงทุนจริงสำหรับผมคนเดียว)เท่านั้น 
ผมไม่รับผิดชอบถ้าคุณเอาไปพอร์ตแตกจริง อันนั้นคุณโง่เอง เพราะถ้าพอร์ตแตกแปลว่าคุณบริหารความเสี่ยงไม่เป็น 
ซึ่งไม่ใช่ความผิดของระบบของผม แต่เป็นความผิดของคุณเองที่ยังฉลาดไม่พอ เสียใจด้วยคุณไม่ใช่ผม

## Features
- จำลองการเทรดแบบเสี่ยงสูง (เทรดแบบกำไรต่ำๆ เช่น S&P500 `มีไว้ให้พวกขี้กลัว`)
- ระบบคำนวณความเสี่ยงที่ `คนฉลาด` ใช้ตัดสินใจ (ไม่ใช่ใช้ดวงล้วนๆ นะครับ แต่มีเหตุผลรองรับ เผื่อจะมาว่าผมว่ารวยเพราะโชคดี)
- Backtest ย้อนหลังให้เห็นว่าถ้าคุณกล้าตั้งแต่เมื่อก่อน วันนี้คุณจะรวยไปแค่ไหน (ไว้ให้คุณรู้สึกเสียดายที่ไม่ใช้โปรแกรมดีๆของผมมาตั้งแต่แรก)
- ลงทุนบ้าน 1 หลัง ได้คืนอย่างน้อย บ้าน 1.3 หลัง ภายใน 1-2 อาทิตย์ (เป็นไงหละ NVDA เป็นไงหละ S&P)
